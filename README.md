# Billing-System

Console billing system in C that creates invoices during program execution and stores data for future reference.

## 🛠️ Features

- Add items to the bill.
- Generate invoices with itemized details.
- Simple and efficient menu-driven interface.

## 📂 Data Handling

The program now saves the generated customer details to a file, allowing you to:
- Retrieve previous customer data on subsequent runs.

## ▶️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/billing-system-c.git
   cd billing-system-c
2. Compile the code:
   ```
   gcc Billing_System.c -o billing_system
3. Run the program:
   ```
   ./billing_system

💡 Make sure you have GCC installed.
